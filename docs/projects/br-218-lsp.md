# Baureihe 218 Livery & Soundpack

![Thumbnail Image](/projects/br-218-lsp/thumbnail.webp)

## Features
- 10 new repaints
- 4 different weathering options
- 218's with removed snowplow
- Implementation of `@Alexander L.`'s Repaint Dependencies Mod
- Accessible machine room!
- Functional GSM-R
- Small details which can be changed via click-spots like the depot of the locomotive (This will also have an affect on the used decals)
- New light textures
- LED version with working high beams

### Audio
This wasn't actually planed at first but following things have been changed:

- New interior and exterior run sounds
- New, two tone horn with separate recordings for inside and outside
- Changed misc sounds like levers, doors and windows
- Redone mixing
