# DB "Abfahrtstafel" - Station PIS Boards

![Thumbnail Image](/projects/misc/pis-boards/thumbnail.webp)

This mod features custom station-wide PIS boards common in large DB stations / termini. These departure boards can be found at the following stations in Train Sim World:

- Dresden Hbf (Bahnstrecke Leipzig - Dresden)
- Dresden Hbf (Nahverkehr Dresden - Riesa)
- Dresden Hbf (Tharandter Rampe: Dresden - Chemnitz)
- Frankfurt Hbf (Frankfurt - Fulda: Kinzigtalbahn)
- Frankfurt Hbf (Frankfurt S-Bahn: S1, S8 & S9)
- Hanau Hbf (Frankfurt - Fulda: Kinzigtalbahn)
- Hamburg Hbf (Hauptstrecke Hamburg - Lübeck)
- Leipzig Hbf (Bahnstrecke Leipzig - Dresden)
- Lindau Hbf (S-Bahn Vorarlberg: Lindau - Bludenz)
- Lübeck Hbf (Hauptstrecke Hamburg - Lübeck)
- München Hbf (Hauptstrecke München - Augsburg)
- Wiesbaden Hbf (Frankfurt S-Bahn: S1, S8 & S9)

*For Hanau Hbf the scenery was modified to make the entrance hall, where the departure board is placed, player-accessible.*

## Known Issues
The quality of the data fed to TSW's PIS system varries from route to route, somtimes resulting in blank/incomplete entries on the display boards.
On Dresden-Riesa Player ↔ AI handovers are split into three services, which the PIS system cannot handle and therefore displays doubled up entries on the modded display boards, there is nothing I can do about this for now I'm affraid.
