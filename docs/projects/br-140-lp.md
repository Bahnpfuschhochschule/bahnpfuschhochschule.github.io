# Baureihe 140 Livery Pack

![Thumbnail Image](/projects/br-140-lp/overview.webp)

This a Livery Pack for SHB's DB BR 140, brought to you by `@Alexander L.`.

## Features

- 4 colour variations (flaschengrün/chromoxidgrün, blau-beige, orientrot, verkehrsrot)
- random texture selection with different levels of dirt
- date-dependent decals
- updated headlight textures by `@Redstoneia`
