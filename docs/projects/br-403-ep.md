# Baureihe 403 Mini-Expansionpack

![Thumbnail Image](/projects/br-403-ep/pic_1.webp)

This mod includes small enhancements for the Nürnberg-Ingolstadt ICE 3 BR 403.

## Features
- Simple GSM-R by `@Foobian`
- company phone (digital Zp9), with a new Samsung Galaxy A35 5G model by `@M3`
- standard EP things (Plushies, "Tür defekt" stickers)
- named units (1. + 2. Bauserie)
- thicker black borders around the doors
- random coupler covers fault
- higher fault probabilities
- Spotlights for headlights and high beams
- new light textures by `@Redstoneia`, with parts by `@Nagiphaaa` and `@Raphael`
- toggleable Zg2 stickers
